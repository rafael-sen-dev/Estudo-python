Estudos de Python: Lógica e Fundamentos
Repositório criado para organizar meus exercícios de lógica de programação e acompanhar minha evolução na linguagem Python.

Conceitos Praticados
 *Estruturas de Repetição:** Loops `while` aninhados e controle de fluxo.
 *Tratamento de Exceções:** Uso de `try/except` para validação de entradas.
 *Manipulação de Strings:** Tratamento de dados com `.title()`, `.lower()` e `.strip()`.
 *Estruturas de Dados:** Manipulação de listas e indexação.

Projeto em Destaque
 *[Atendimento.py](./pizzaria-roberto-carlos):** Mini-sistema de terminal que simula o atendimento de uma pizzaria. Valida itens do cardápio, impede quantidades inválidas, gerencia o carrinho e aplica desconto para estudantes.
