 Estudos de Python: Lógica e Fundamentos

Repositório criado para organizar meus exercícios de lógica de programação e acompanhar minha evolução na linguagem Python.

 Conceitos Praticados
    Estruturas de Repetição: Loops `while` aninhados e controle estruturado de fluxo [3].
    Tratamento de Exceções: Uso de `try/except` para validação robusta de entradas de dados e prevenção de quebras de execução.
    Manipulação de Strings: Tratamento, higienização e formatação de textos usando `.title()`, `.lower()` e `.strip()`.
    Estruturas de Dados: Manipulação dinâmica de listas, fatiamentos (`slices`), indexação e uso de dicionários aninhados (estruturas hash).
    Arquitetura e Modularização: Organização de um sistema complexo em múltiplos arquivos Python independentes (evitando ciclos de importação e gerenciando o escopo de memória) [1].

 Projeto em Destaque
    Pizzaria Roberto Carlos(./pizzaria-roberto-carlos): Sistema integrado via terminal que simula a jornada completa de atendimento do cliente e o portal de gerenciamento administrativo (controle de estoque, fluxo de caixa e auditoria de pedidos).
    Área do Cliente: Cardápio dinâmico, adição de bordas, bebidas e tamanhos com cálculo automático de área (cm²) e emissão de recibo detalhado.
    Área de Administração: Verificação e reabastecimento de ingredientes no estoque, movimentação do caixa e conclusão segura de pedidos sob demanda .

 Como Executar

1.Clone o repositório:
    git clone https://github.com/seu-usuario/seu-repositorio.git
    Navegue até a pasta do projeto:
    cd pizzaria-roberto-carlos
    Execute o arquivo principal no terminal:
    python main.py

Este projeto foi desenvolvido exclusivamente para fins educacionais e didáticos, como parte dos estudos de lógica de programação, modularização e estruturas de dados em Python.

Por se tratar de um protótipo acadêmico:

    Armazenamento Volátil (RAM): Os dados são reiniciados sempre que o programa é fechado.

    Segurança Simplificada: O código não adota criptografia ou protocolos avançados de segurança comercial.

    Uso Recomendado: É um simulador CLI (terminal) focado em consolidação algorítmica. Não é recomendado ou seguro para uso profissional ou comercial em produção.
